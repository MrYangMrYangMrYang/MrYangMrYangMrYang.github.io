# UI 组件工坊

基于 CSS 变量的组件库，展示设计系统与主题切换能力。

## 技术栈

- HTML5
- CSS3（CSS Variables / 主题切换 / 过渡动画）
- JavaScript（主题持久化 / 模态框交互）

## 功能特性

- **按钮**：6 种变体（主要/成功/警告/危险/描边/幽灵）、3 种尺寸、禁用状态
- **输入框**：标签、占位符、聚焦高亮、错误状态与提示
- **卡片**：图片区、内容区、标签与操作按钮
- **标签**：5 种语义色彩变体
- **开关**：滑动切换动画
- **提示框**：4 种类型（信息/成功/警告/危险），暗色模式适配
- **模态框**：遮罩层、缩放动画、点击外部关闭
- **主题切换**：亮色/暗色模式，localStorage 持久化
- 响应式适配（900px / 600px 断点）

## 项目结构

```
ui-components/
├── index.html    ← 页面结构与交互逻辑
├── style.css     ← 样式与主题变量
└── README.md     ← 项目说明
```
