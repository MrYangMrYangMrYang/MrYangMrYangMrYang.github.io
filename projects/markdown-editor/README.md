# Markdown 在线编辑器

左右分栏实时预览的 Markdown 编辑器，展示字符串处理与正则表达式能力。

## 技术栈

- HTML5
- CSS3（Flexbox / 自定义滚动条 / Catppuccin 主题）
- JavaScript（正则表达式 / DOM 操作 / 文本处理）

## 功能特性

- 左右分栏实时预览
- 工具栏快捷插入（标题/加粗/斜体/代码/链接/表格等）
- 自写 Markdown 解析器，支持：
  - 标题（H1-H4）
  - 加粗、斜体、删除线
  - 行内代码、代码块
  - 链接、图片
  - 有序/无序列表
  - 引用块
  - 表格
  - 分割线
- Tab 键缩进支持
- 字符数/行数统计
- 响应式适配（768px / 480px 断点，移动端上下分栏）

## 项目结构

```
markdown-editor/
├── index.html    ← 页面结构与编辑器逻辑
├── style.css     ← 样式表
└── README.md     ← 项目说明
```

## 预览

在浏览器中打开 `index.html` 即可预览。
