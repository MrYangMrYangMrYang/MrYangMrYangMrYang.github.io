# 数据仪表盘

基于 Canvas API 的数据可视化仪表盘，展示图表绘制与数据展示能力。

## 技术栈

- HTML5
- CSS3（Grid 布局 / 响应式断点）
- JavaScript（Canvas API / 数据可视化）

## 功能特性

- 4 个核心指标统计卡片（含趋势变化）
- 折线图：访问趋势，带渐变填充与数据点
- 柱状图：各页面访问量，带圆角与渐变
- 环形饼图：流量来源分布，带图例
- 热门页面与地区分布列表
- 季度目标进度条
- 实时时钟与状态指示
- 窗口缩放时图表自适应重绘
- 响应式布局（4列 → 2列 → 1列）
