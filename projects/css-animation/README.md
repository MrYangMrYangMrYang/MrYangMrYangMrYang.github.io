# CSS 动效实验室

纯 CSS 实现的动画效果集合，展示 CSS 动画与过渡能力。

## 技术栈

- HTML5
- CSS3（Animation / Transition / Transform / Keyframes）
- JavaScript（仅用于波浪文字 DOM 生成）

## 功能特性

- **Loading 动画**：旋转圆环、弹跳圆点、脉冲扩散、滑动进度、翻转方块
- **Hover 交互**：缩放渐显、渐变描边、底部滑入、光泽扫过
- **文字动画**：打字机效果、渐变流动、波浪弹跳
- **视差浮动**：纯 CSS 多层浮动视差
- 响应式适配（900px / 600px 断点）

## 项目结构
