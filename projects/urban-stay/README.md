# UrbanStay 品牌页

现代品牌落地页，展示 Flex/Grid 布局与响应式设计能力。

## 技术栈

- HTML5
- CSS3（Flexbox / Grid / 响应式断点）
- JavaScript（移动端菜单交互）

## 功能特性

- 固定导航栏，滚动时毛玻璃效果
- Hero 区域双栏布局，含产品卡片预览
- 特色功能卡片网格
- 房间展示卡片，悬浮动效
- 住客评价区域
- CTA 行动号召区域
- 移动端汉堡菜单
- 三档响应式断点（900px / 600px）
