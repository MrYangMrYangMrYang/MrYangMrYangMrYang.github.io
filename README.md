## 功能特性

- **暗色/亮色主题切换** — 基于 `prefers-color-scheme` 自动检测，LocalStorage 记忆用户偏好
- **移动端适配** — 768px / 480px 双断点响应式布局，汉堡菜单
- **区域标题动效** — 蓝紫渐变流动动画 + 装饰下划线 + 副标题，暗色模式同步适配
- **平滑滚动** — 锚点链接平滑过渡动画
- **滚动位置记忆** — 从子项目返回时自动恢复浏览位置
- **无障碍支持** — Skip-link、ARIA 标签、语义化 HTML
